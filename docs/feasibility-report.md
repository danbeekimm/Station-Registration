# 발령 가능성 검토 — 전체 출력

README 4절의 결론을 뒷받침하는 `./gradlew -q feasibility`의 전체 출력이다. 서버와 **같은 파서·룰 엔진**으로 데이터 파일을 훑어 생성하며,
"기록 건수"는 시각마다 최고 등급 1건만 남기는 `alert_log` 기준이라 시뮬레이터로 재생한 뒤의 DB 건수와 같다.
**은평구는 제공 데이터가 아닌 가상 데이터**이므로 발령 가능성 결론은 노원구·중구·강서구 세 측정소로 판단한다.
